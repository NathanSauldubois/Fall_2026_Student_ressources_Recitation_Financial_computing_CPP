FRE6883 -- Financial Computation
Recitation 2: Structured Programming and CRR Code Lab

AUDIENCE BASELINE
Students have completed Lecture 2. They have seen sequential, conditional, and
iterative control flow; binomial stock nodes; nested loops; fixed-size arrays;
input validation; functions; namespaces; pass by value/reference; and the CRR
backward-induction pricer. This recitation emphasizes retrieval, completion,
tracing, debugging, and integration rather than first exposure.

SESSION OUTCOME
By the end, students can complete, trace, test, and explain a small modular CRR
pricer because they have rebuilt it from independently testable functions and
verified the data flow from model inputs to Price[0].

FORMAT
38 core Beamer frames, approximately 100 minutes. Thirteen guided activities use
a problem frame followed by a solution frame (the final integration activity
uses two problem and two solution frames). Students first predict or complete
code, then compare and explain. Ten additional reserve frames at the end reuse
four problem/solution pairs from Recitation 1 Deck 5. Timings below include
student work and discussion but exclude the reserve practice.

ACTIVITIES
1. Complete CalculateAssetPrice from the stock-node formula.
2. Complete nested loops that visit every node exactly once.
3. Store all visited nodes in a one-dimensional array.
4. Complete model-data and no-arbitrage validation.
5. Implement and hand-check RiskNeutProb.
6. Predict pass-by-value and pass-by-reference effects.
7. Complete GetInputData with output references.
8. Implement CallPayoff with a boundary case at the strike.
9. Fill the terminal option-value row.
10. Complete the backward-induction loops and update.
11. Diagnose why a decreasing inner loop corrupts in-place data.
12. Assemble a guarded, standard-C++ PriceByCRR function.
13. Compute the local CRR delta before overwriting child option values.

RESERVE PRACTICE FROM RECITATION 1 DECK 5
- Count positive values.
- Running sum.
- Richest customer.
- Best time to buy and sell stock.

TECHNICAL NOTES
- The deck follows the visual and C++ conventions of Recitation 1 Decks 1 and 5.
- The model uses gross one-period factors with 0 < D < R < U and S0 > 0.
- The corrected no-arbitrage test is R <= D || R >= U. Lecture 2 pages 24-25
  show U <= D in the second condition; that repeats an earlier range test and
  fails to reject R <= D.
- The final pricer uses a fixed compile-time capacity SIZE = 9 and accepts
  1 <= N <= 8. This avoids Lecture 2's variable-length array, which is not
  standard C++.
- CRR uses the Lecture 2 parameters S0=106, U=1.15125, D=0.86862,
  R=1.00545, K=100. For a short N=2 trace, terminal payoffs are approximately
  [0,6.00,40.49], the time-1 row is [2.8890,22.5745], and Price[0] is 12.3521.
  At the root, delta is approximately 0.6571: hold 0.6571 share and borrow
  approximately 57.30. Delta must be computed before the in-place overwrite.
  The complete Lecture 2 N=8 program returns 21.68.
- Solution frames are intentionally separate so the instructor can stop before
  revealing them.
